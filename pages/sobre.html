Sobre o FolioLabs

Uma jeito novo de criar seu portfólio

Nossa Ideia

A ideia nasceu da dificuldade que meu amigo, e muitos outros devs, têm para criar um portfólio personalizado. Percebi que faltava uma plataforma que unisse a credibilidade profissional do LinkedIn com a liberdade criativa do Canva.

A proposta é um site onde o usuário possa construir seu portfólio de forma descomplicada, escolhendo layouts e cores, mas mantendo seções essenciais para um programador, como exibição de projetos, habilidades técnicas e bio. É sobre empoderar o dev para que ele mostre seu talento com uma identidade visual única, sem precisar perder tempo com código de apresentação. .

Recursos que utilizamos

Utilizamos alguns recursos para fazer que este projeto saísse de uma ideia para codigo

- Programação HTML5, CSS3 e JavaScript

- Banco de Dados SupaBase

- Manus IA - Para Auxilio do Backend

- Deep Seek - Para responder perguntas sobre estrutura de codigos

- GitHub - Para controle de versionamento

- Netlify - Para hospedagem do Site na Internet
